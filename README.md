# ATLAS WILDS ARENA

Мобильная 3D fantasy action RPG на **Unreal Engine 5.5**. Основная цель — исследуемый открытый мир с существами, боем и развитием героя.

## Уже подготовлено в репозитории
- UE5.5 C++ project: `AtlasWildsArena.uproject`.
- Игровой режим `AAtlasGameMode`, который запускает прототипный мир и точку появления игрока.
- `AAtlasPlayerCharacter`: камера от третьего лица, ходьба, поворот камеры, прыжок, временная геометрия персонажа.
- `AAtlasWorldGenerator`: процедурная расстановка деревьев, камней, холмов и тестового русла реки из базовых мешей движка.
- Android настройки: ARM64, Landscape, пакет `com.atlaswilds.arena`.
- Базовая поддержка touch input и стандартного виртуального джойстика Unreal.
- Сохранены `UnityProject/`, `assets/` и `tools/` как отдельные материалы/заготовки.

## Открытие проекта
Откройте `AtlasWildsArena.uproject` в Unreal Engine 5.5. При первом запуске редактор должен сгенерировать проектные файлы и собрать C++ модуль. Это обязательная проверка: исходники пока не проходили компиляцию в Unreal Editor.

## Текущие ограничения
Это ранний технический прототип, не законченная игра. Процедурный мир использует примитивные стандартные меши; финальных моделей, анимаций, врагов, квестов, инвентаря и боевой системы пока нет. APK ещё не собран.

Обычный GitHub Actions runner не содержит Unreal Engine. Для реальной Android-сборки требуется доступная среда с установленным UE 5.5 и совместимыми Android SDK/NDK/JDK. Наличие одного лишь GitHub workflow не заменяет Unreal Engine.
