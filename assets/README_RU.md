# Модели животных ATLAS WILDS

Сюда GitHub Actions автоматически распакует две модели из ZIP-файлов в корне репозитория:

- `ATLAS_WILDS_Polar_Bear_3D.zip` → `assets/Polar_Bear.glb`
- `ATLAS_WILDS_Ice_Dragon_3D.zip` → `assets/ATLAS_WILDS_Ice_Dragon.glb`

Если архивы ещё не загружены, игра временно использует простые заглушки. Чтобы включить настоящие модели, загрузи оба исходных ZIP в корень репозитория и дождись новой сборки APK.
