# SHADOW ARENA — Unreal Engine 5

Новый отдельный проект на Unreal Engine 5. Старые файлы Godot удалены из текущей версии ветки main.

## Состояние
Это стартовый C++ каркас для дальнейшей разработки, а не готовая игра и не собранный APK. В репозитории пока нет бинарных Unreal-ассетов и Android APK.

## Открытие на ПК
1. Установить Unreal Engine 5.4 через Epic Games Launcher.
2. Скачать репозиторий целиком.
3. Открыть `ShadowArena.uproject`; согласиться с генерацией файлов проекта.
4. Скомпилировать проект в Unreal Editor.
5. Для Android установить Android Studio/SDK и настроить Android SDK в Unreal.
6. В Project Settings → Platforms → Android настроить пакет приложения, затем Package Project → Android (ASTC).

## Первый этап
Собрать полноценную игровую основу: персонаж, камера, управление касанием, противники, бой, интерфейс, звук и оптимизация под Android.
