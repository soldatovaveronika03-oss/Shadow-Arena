- `43293218-c338-4fe2-a177-32a10bffe72c.glb` — 21.5 MB
- `bdd1f502-bdb6-4287-8d2c-7799487a4999.glb` — 22.1 MB

Файлы сохранены без переименования, чтобы не потерять связь с оригинальными загрузками. Содержимое моделей и назначение каждой нужно подтвердить импортом в Unreal Editor.

## Импорт в Unreal Engine 5.5
GLB — исходные файлы моделей. Их нужно импортировать через совместимый glTF/Interchange importer в Unreal Editor, проверить материалы, масштаб, скелет и анимации, затем сохранить полученные Unreal assets в папку Content проекта.

Само наличие GLB в папке assets не означает, что Unreal автоматически включит их в APK. До сборки необходимо выполнить импорт и проверить модели в редакторе.
