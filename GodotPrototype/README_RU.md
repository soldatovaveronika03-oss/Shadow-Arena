# ATLAS WILDS ARENA — временный тестовый прототип Godot

Это отдельный технический прототип для получения тестовой Android APK. Основной проект Unreal Engine 5.5 в корне репозитория не изменяется.

## Что есть в тесте
- небольшой процедурный 3D-ландшафт;
- персонаж-заглушка в бело-золотом стиле;
- камера от третьего лица с вращением свайпом;
- сенсорные кнопки движения и атаки;
- три GLB-модели из общей папки `assets/` размещены впереди как демонстрационные модели.

## Ограничения
Это ранний тест управления и импорта моделей, а не готовая RPG. Модели пока не назначены игровым персонажем или врагами, их назначение и масштаб нужно проверить в игре. Нет квестов, сохранений, полноценного боя, анимаций и сетевой игры.

## Сборка
GitHub Actions workflow: **Build ATLAS WILDS Godot Android APK**. После успешной сборки APK будет доступен в Artifacts соответствующего запуска.
