# ATLAS WILDS ARENA — основной проект Godot

**Активный игровой движок: Godot 4.7.2.** Папка `GodotPrototype/` — основная рабочая версия игры для Android. Файлы Unreal/Unity в корне репозитория не используются для текущей сборки.

## Текущая основа
- Процедурный 3D-рельеф с долиной у точки появления и горным обрамлением.
- Земля с процедурным материалом травы, почвы и камня.
- Физическая коллизия ландшафта.
- Извилистая грунтовая дорога, озеро и русло реки.
- Инстансированная растительность и камни для снижения количества Draw Calls.
- Поддержка GLB-моделей Кайрона и существующих пользовательских существ.
- Сенсорный джойстик, свайп камеры, прыжок, атака, сбор ресурсов, крафт и строительство.
- Android-проект с рендерером GL Compatibility.

## Blender-модели окружения
Скрипт `BlenderPreview/create_trees.py` создаёт четыре самостоятельные GLB-модели деревьев. Workflow **Build Blender Environment Assets** переносит готовые GLB в `GodotPrototype/assets/generated/` и прикладывает PNG-превью как GitHub Actions artifact.

## Сборка и проверка
Workflow **Build ATLAS WILDS Godot Android APK** выполняет headless-импорт, проверку запуска и экспорт APK. APK считается проверенным только после успешного завершения всех шагов workflow. Реальное тестирование на Android-устройстве выполняется отдельно.

## Важные ограничения текущего этапа
Это продолжающаяся реконструкция мира, а не завершённая RPG. Процедурные объекты пока являются мобильными базовыми моделями; полноценный Landscape-редактор, сложные анимации существ, квесты и сохранения ещё требуют отдельной разработки.
